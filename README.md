## 项目简介

本仓库是一个 Agent Skill，主题是 Electron 桌面软件的授权机制。它只回答"为什么"，不回答"怎么做"：

- **结构**：Electron 应用如何组织（asar 归档、主/渲染进程、jsc 字节码、出厂熔断开关）。
- **形态**：卡密/激活体系五种常见校验形态，从纯本地明文到纯云端判定。
- **数学**：为什么带 RSA 签名的激活码造不了假——非对称签名与计算困难性。
- **失效**：授权设计里反复出现的失效模式——接口可替换性、校验边界、隐式契约。
- **自查**：面向软件作者与自购用户的授权健壮性问答清单。

配套 SKILL.md 是主入口，供 Agent 加载；`references/` 下的两篇长文是给人深读的展开材料。
